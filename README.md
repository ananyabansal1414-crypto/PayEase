# PayEase Global Connect (Prototype)

One wallet for every payment network. A clickable prototype of a unified global payment flow.

## Features
- Choose a country and see its supported payment apps (UPI, Alipay, Pix, SEPA and more)
- Smart payment recommendation (lowest total cost)
- Currency and fee calculator that shows amounts in your home currency and the destination currency
- AI-style fraud risk score and code verification (demo code: `1234`)
- Confirm or cancel, success or failure, refund tracking
- Unified transaction history

## Run it
Open `index.html` in any browser. No install or build step.

## Notes
- Exchange rates and fees are illustrative demo values, not live data.
- Built as a prototype for the PayPal x PayEase idea (problem, solution, tech approach, business model slides).

## Planned tech stack
Next.js, TypeScript, Tailwind CSS, Node.js, NestJS, Supabase, OAuth 2.0, JWT, AWS, Docker, GitHub Actions.
